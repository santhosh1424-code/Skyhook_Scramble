# Asset Credits & Licences — Treasure Isle

## Included Assets (Generated / Procedural — CC0)
All models, textures, and audio currently bundled in this repository were generated procedurally so the game runs 100% offline with zero external network dependencies or licence ambiguity:
- **Rigged Humanoid & Modular Clothing GLBs (`/assets/models/*.glb`):** Procedurally generated valid binary glTF 2.0 (`GLB`) skinned meshes sharing a unified 22-bone humanoid skeleton (`Hips` → `Spine` → `Chest` → `Neck`/`Head`/`Arms`/`Legs`), UV-mapped and generated by `scripts/generate-assets.mjs`. Licence: **CC0 / Public Domain**.
- **PBR Terrain, Water, Cloth, Leather & Metal Textures:** Procedurally synthesized in-memory `CanvasTexture` / `DataTexture` albedo, normal, and roughness maps. Licence: **CC0 / Public Domain**.
- **Audio & Pirate Shanty:** Procedurally synthesized via the Web Audio API (ocean surf, wind gusts, bird chirps, surface footsteps, shovel dig, chest creak, cutlass clang, and modal Dorian shanty). Licence: **CC0 / Public Domain**.

## Optional Real-Asset Drop-In Guide (Mixamo / Quaternius / Poly Haven)
If you want to swap the procedural placeholder humanoid GLBs for studio-sculpted characters and scanned PBR textures:
1. **Characters & Animations (Mixamo — Free with Adobe account, royalty-free for commercial/non-commercial games; or Quaternius Ultimate Pirate Pack — CC0):**
   - Download a T-pose humanoid `.fbx`/`.glb` and animation clips (`idle`, `walk`, `run`, `sprint`, `jump`, `dig`, `slash`, `swim`) and convert via Blender to `.glb` (Draco-compressed).
   - Keep the bone names mapped in `/client/src/character/skeletonMap.ts` and drop the files into `/assets/models/` (`body_male.glb`, `body_female.glb`, etc.).
2. **PBR Textures & HDRI (Poly Haven — CC0):**
   - Download 1K/2K `sand_02`, `forest_leaves_02`, `rock_face_03`, `mud_01` textures + a coastal tropical HDRI (`kloofendal_48d_partly_cloudy_1k.hdr`) from https://polyhaven.com/ and place them in `/assets/textures/` and `/assets/hdri/`.
   - The asset loader in `/client/src/assets/assetLoader.ts` automatically supports `GLTFLoader` + `DRACOLoader` + `KTX2Loader` once those files are placed in `/assets/`.
